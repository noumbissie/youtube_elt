                 ****-----------------------------------------------INFOS UTIL 2---------------------------------------****
                 
**On utilise pytest si :
on développes une application Python
on écris des fonctions
on fais de l’API/backend
on veux des tests unitaires

**On utilise Soda si :
on travailles en data engineering
on vérifies des pipelines ETL
on contrôles des tables SQL
on fais de la qualité de données

***Ils peuvent être utilisés ensemble

Dans un vrai projet data :

Python → transforme les données
pytest → teste le code Python
Soda → teste les données produites
